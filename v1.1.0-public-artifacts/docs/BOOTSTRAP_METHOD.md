# Independently specified five-seed paired-flow bootstrap

All 320 per-evaluation NPZ predictions were generated by retraining the frozen source-only benchmark on the four harmonized datasets. Each regenerated TN/FP/FN/TP exactly matched the archived counts. For a particular source-target direction, each target test row is aligned by positional index across four models and five fixed seeds. We compute the mean correctness on every flow over the 20 predictors. Within each true class, we sample with replacement the original number of flows; the same sampled flow contributes simultaneously to all 20 predictors. Balanced accuracy in each bootstrap sample is half the average per-flow correctness for benign plus half the average for attacks. We apply 2,000 stratified nonparametric percentile replicates with RNG seed 20261105. The categorical multinomial draw on the integer count of positive predictions (0..20) is mathematically distributionally equivalent for this statistic to sampling shared per-flow indices; the compression is exact, not a Gaussian approximation. Each direction marginal CI is computed separately; pairwise differences of two different training-source directions are *not* inferred from those separate intervals. This is a NEW, FULLY REPRODUCIBLE 5-seed flow bootstrap, NOT a bit-for-bit recreation of unknown historical 2,000 RNG draws. It is conditional on the fixed test partitions and five seeds, not host/session clustered, so no population-level/generalized significance claims. Indices are positional, not original physical-flow IDs.
