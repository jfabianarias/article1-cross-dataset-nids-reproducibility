This release candidate consolidates the cross-dataset NIDS experiments and supplementary checks supporting the manuscript. The frozen, separate **public Overleaf archive** is `NIDS_Overleaf_Candidato_Publicacao_Validado_2026-11-06.zip` (6,653,161 bytes). SHA-256:

## Validation

- 320 source–target–model–seed prediction files have been validated privately against SHA-256 and archived TN/FP/FN/TP counts.
- The 16 five-seed direction-level paired class-stratified confidence intervals were regenerated byte-for-byte (2,000 bootstrap draws).
- The 48 external transfer-cell confidence intervals were regenerated byte-for-byte (20,000 bootstrap draws); 25 nominal and 24 Bonferroni-adjusted intervals have an upper bound below BA=0.5.
- The public archive contains **609 ZIP entries**, passed ZIP CRC, and contains no NPZ, NPY, parquet, joblib, pickle, or private-key artifacts.
- LODO and random undersampling controls were independently rerun, **not** bitwise historical reproductions.
- The newly specified five-seed bootstrap is independent and reproducible; it is **not claimed** to reproduce the exact historic RNG draw sequence. No host/session-cluster robust CI is claimed.

## Separation of public and private artifacts

Never add `NIDS_Predicoes_320_Cinco_Sementes_PRIVADO.zip` or harmonized third-party dataset partitions to the public repository, release assets or Zenodo. The privately retained 320 predictions are not part of this public archive. The public package includes auditable aggregate results, code, figures, and provenance manifests.

## Publication gates

1. Review the manuscript, author/affiliation metadata, and provider redistribution terms.
2. Ensure the public reproducibility code and artifacts intended for the release are **actually committed** in GitHub, not only available as a local ZIP. The Zenodo GitHub integration archives the repository release snapshot; release assets should be separately deposited if necessary.
3. Preserve `v1.0.1`. Publish a new `v1.1.0` tag only from the reviewed final commit.
4. Attach the exact checked public ZIP; verify SHA-256 again after uploading.
5. After Zenodo archives the new release, record the **new version DOI** in citation metadata. Do not reuse the previous version DOI as the new version's identifier.
